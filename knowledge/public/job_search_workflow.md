# 职业检索能力 · 岗位能力调研工作流

> 本文档描述如何从可访问的公开渠道系统性地收集、整理和结构化岗位能力数据。
> 产出格式统一，可被 RAG 检索。

---

## 一、可用渠道

| 渠道 | 方式 | 能拿到什么 |
|------|------|-----------|
| `web_search` | Agent 直接调用 | 搜索结果摘要（公司名、部分职责、部分要求） |
| 各公司招聘官网 | 直接访问 | 完整JD（职责+要求+加分项） |
| CSDN / 人人都是产品经理 / 掘金 | 直接访问 | JD分析文章、面经汇总 |
| 牛客网 (nowcoder.com) | 直接访问 | 校招面经+JD讨论 |

可直接访问的招聘官网：
- 阿里：campus-talent.alibaba.com
- 腾讯：careers.tencent.com
- 美团：zhaopin.meituan.com
- 百度：talent.baidu.com
- 字节：jobs.bytedance.com

## 二、Agent 执行流程

```
Step 1: web_search
  查询词："{岗位名称} 岗位职责 核心能力 JD"
  获取搜索结果摘要

Step 2: 补充搜索
  - "{岗位名称} 校招 site:nowcoder.com"
  - "{岗位名称} JD 汇总 site:csdn.net"
  - "{公司名} {岗位名称} 招聘"

Step 3: 官网直采
  逐个访问公司招聘官网获取完整JD

Step 4: 交叉归纳
  从多个来源归纳能力列表，按模板输出结构化文件
  标注每个能力的数据来源类型

Step 5: 写入 knowledge/jobs/ 目录
```

## 三、交叉归纳方法

### 3.1 单条 JD 提取清单

从每个 JD 中提取以下字段（缺的标注"未提及"）：

- 公司名称、岗位名称、地点
- 经验要求（校招/1-3年/3-5年/不限）
- 来源 URL
- 岗位职责（逐条）
- 任职要求（逐条）
- 加分项（如有）

### 3.2 归纳步骤

1. **逐条通读**：把所有 JD 的"岗位职责"和"任职要求"摊开看
2. **提取关键词**：统计高频出现的能力词（出现次数 ≥3 的优先记录）
3. **合并同类项**：不同 JD 对同一能力的不同表述合并——比如"用户调研""需求挖掘""痛点识别"合并为"需求洞察"
4. **标注出处**：每条归纳后的能力至少标注 2 个来源 JD
5. **区分层级**：同一能力在校招和社招 JD 中的要求不同——校招说"了解"，社招说"深度理解+实操"

### 3.3 质量检查清单

- [ ] 每个能力板块至少对应 2 个 JD
- [ ] 来源 URL 可访问（或标注访问时间）
- [ ] 校招/社招的能力要求有明确区分
- [ ] "典型工作"来自 JD 原文归纳，不是自己编的
- [ ] 如果某条能力只有搜索摘要支撑，标注"待补充完整 JD 验证"

## 四、岗位文件格式模板

每个岗位一个 Markdown 文件，放在 `knowledge/jobs/` 目录下，命名：`{岗位名}.md`。

```markdown
# {岗位名称} · 岗位能力参考库

> 基于 N 个 JD / 社区文章交叉归纳。覆盖校招、社招等层级。
> 数据收集时间：YYYY-MM-DD

## 一、能力全景
（用一句话概括这个岗位的能力结构）

## 二、核心能力
（按能力板块分节，每节用表格，标注来源）

| 能力项 | 具体表现 | 来源 |
|--------|---------|------|
| ... | ... | 腾讯JD、美团JD |

## 三、按经验层级的能力侧重

| 层级 | 核心考察 | 工具/技术要求 | 经验期望 |
|------|---------|-------------|---------|
| 校招/实习 | ... | ... | ... |
| 1-3年 | ... | ... | ... |
| 3-5年 | ... | ... | ... |

## 四、典型工作
（来源：JD 职责项交叉归纳）

## 五、给大学生的对照指南

| 你有这个 | 怎么对标 JD |
|----------|-----------|
| ... | ... |

## 六、JD 来源清单

| 序号 | 来源类型 | 代表性内容 | 收集方式 |
|------|---------|-----------|---------|
| 1 | ... | ... | 官网直采 / 社区文章 / 搜索摘要 |
```

格式约束：
- 每条能力必须有来源标注，禁止"据悉""据调查""市场上"等模糊表述
- 区分"JD 明确要求"和"综合趋势判断"，后者加标注
- 技术术语首次出现时加简短解释
