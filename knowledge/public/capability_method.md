# 能力方法库

## STAR 追问话术

### 背景与角色（Situation）
- "这个项目是做什么的？你当时的角色是什么？"
- "团队有多少人？你负责哪个部分？"
- "项目的背景是什么？要解决什么问题？"

### 具体行动（Action）
- "你具体做了哪些事？用了什么工具或方法？"
- "为什么选择这个方法？有没有评估过其他方案？"
- "能描述一下你典型一天的工作内容吗？"

### 困难与应对（Challenge）
- "过程中最难的是什么？你是怎么解决的？"
- "有没有遇到意见不一致的情况？你怎么处理的？"
- "如果重来一次，你会怎么做？"

### 成果量化（Result）
- "结果怎么样？有没有具体数字可以说明？"
- "其他人怎么评价你的工作？"
- "这个成果和你最初的预期相比如何？"

## 能力卡生成规则

### 证据类型判断
- **事实 (fact)**: 有证书、可查证记录、第三方证明
- **自述 (self_report)**: 用户自己描述的行为，未经第三方验证
- **推断 (inference)**: 基于多条自述综合推测，必须标注推理依据
- **未知 (unknown)**: 信息不足，无法判断

### 追问触发条件（仅四种情况允许追问）
1. 缺少用户具体做了什么
2. 缺少结果或产出
3. 无法区分团队成果和个人贡献
4. 能力推断明显超过证据

### 追问上限
- 每种缺口最多追问3次
- 每次追问必须说明原因

## 能力卡格式

```
【能力卡：{能力名称}】
- 能力描述：{一句话概括}
- 证据来源：{用户原话引用或简历出处}
- 证据类型：{fact/self_report/inference/unknown}
- 推断依据：{仅推断类型需要}
- 待验证：{是/否}
- 对标岗位要求：{对应的岗位要求原文 + 来源标注}
- 追问建议：{信息不够时补充什么}
```

## 经历卡格式

```
【经历卡：{经历名称}】
- 时间：{发生时间}
- 背景：{什么情况下做的}
- 行动：{具体做了什么}
- 结果：{产生了什么结果}
- 来源：{简历第X页第Y段}
```
