# 用户体验设计师 · 岗位能力参考库

> 基于 web_search 摘要 + 腾讯/美团官方JD + 社区文章（人人都是产品经理、CSDN、UXlib）交叉归纳。
> 覆盖校招、社招两个层级。
> 数据收集时间：2026-08-11

---

## 一、能力全景

用户体验设计师 = **用户洞察力 × 交互设计力 × 视觉表现力 × 协作推动力**

和 AI 产品经理不同，UX 设计师的硬技能门槛更明确——工具链、设计规范、作品集是入场券，软技能（沟通、同理心、设计思维）决定天花板。

| 层级 | 能力板块 | 说明 |
|------|---------|------|
| 底座 | 视觉与工具能力 | Figma/Sketch/PS/AI 等工具精通，UI 规范、设计系统搭建——所有 JD 提及 |
| 核心 | 交互与体验设计 | 信息架构、用户流程、线框图、原型制作、可用性评估——UX 岗的核心区分力 |
| 溢价 | 用户研究能力 | 访谈、可用性测试、问卷、用户画像——大厂 JD 越来越要求 UX 设计师具备用研能力 |

## 二、核心能力

### 2.1 交互设计能力（6/8 JD 提及）

| 能力项 | 具体表现 | 来源 |
|--------|---------|------|
| 信息架构 | 组织、构造和标记内容，创建清晰的导航与层级 | 腾讯JD、UXlib框架 |
| 用户流程设计 | 设计端到端的用户旅程，梳理任务流程图与状态转换 | 腾讯JD"输出清晰的信息架构、完整的页面流程" |
| 线框图与原型 | 低保真到高保真的快速原型制作，支持可交互演示 | 美团JD、腾讯JD |
| 交互规范 | 理解并应用人机交互标准与设计模式，选择正确控件 | UXlib框架 |
| 动效设计 | 通过动画简化界面操作，提升交互反馈与视觉体验 | 腾讯JD"动效节奏设计"、高校人才网JD |
| 多端适配 | 移动端/桌面端/Web端设计能力，了解各端设计规范 | 腾讯JD"移动端/桌面端/web端"、高校人才网JD |

### 2.2 视觉设计能力（5/8 JD 提及）

| 能力项 | 具体表现 | 来源 |
|--------|---------|------|
| 视觉表现 | 色彩、排版、布局、图标等基本功扎实 | 高校人才网JD"审美能力突出，扎实的美术功底" |
| 设计系统 | 建立并维护组件库、样式指南，提升设计一致性 | 高校人才网JD"建立并维护产品设计规范" |
| 品牌设计 | 把控产品视觉风格与品牌调性 | IBM JD"品牌设计师" |
| 工具精通 | Figma、Sketch、PS、AI、XD——Figma为首选 | 所有JD |

### 2.3 用户研究能力（4/8 JD 提及，大厂JD尤其强调）

| 能力项 | 具体表现 | 来源 |
|--------|---------|------|
| 用户访谈 | 结构化访谈，超越表象揭示用户目标 | 腾讯JD"开展用户调研"、UXlib |
| 可用性测试 | 策划和执行可用性测试，记录分析数据 | 腾讯JD"可用性测试"、UXlib |
| 用户画像 | 创建人物画像与典型场景 | UXlib框架 |
| 数据分析 | 结合用户反馈数据与行为分析优化设计 | 腾讯JD"关注体验数据与用户反馈" |
| 竞品分析 | 用户体验层面的竞品研究 | 腾讯JD |

### 2.4 工具链能力（所有JD提及）

| 工具类型 | 具体工具 | 要求程度 |
|---------|---------|---------|
| 核心设计 | Figma（首选）、Sketch、Adobe XD | 精通 |
| 图像处理 | Photoshop、Illustrator | 熟练 |
| 动效 | After Effects、Principle | 加分项 |
| 原型 | Axure、墨刀、蓝湖 | 熟练 |
| 3D（加分项） | C4D、Blender | 了解即可 |
| 协作 | Notion、飞书文档 | 日常使用 |

### 2.5 软性素质（贯穿所有 JD）

| 素质 | 来源 |
|------|------|
| 沟通能力 | 腾讯JD"与产品经理、开发紧密配合"；美团JD"良好的目标导向思维" |
| 同理心 | UX 研究员核心软技能——理解用户但不盲信用户 |
| 逻辑思维 | 腾讯JD"良好的逻辑能力"；美团JD"用户思维和逻辑思维好" |
| 自驱力 | 腾讯JD"自驱、有创作激情"；woshipm能力模型 |
| 用户视角 | 美团JD"注重用户体验，具备优秀审美和一定的UX设计能力" |

## 三、按经验层级的能力侧重

| 层级 | 核心考察 | 工具要求 | 经验期望 |
|------|---------|---------|---------|
| 校招/实习 | 审美基本功 + 设计思维 + 学习潜力 | Figma/PS/AI 熟练，有作品集 | 有 UI/UX 实习或项目经验加分 |
| 1-3年 | 独立完成设计需求 + 交互逻辑清晰 | 精通核心工具，能搭建组件库 | 参与过完整产品设计周期 |
| 3-5年 | 主导设计方向 + 设计系统建设 + 用研能力 | 能带设计规范、沉淀方法论 | 主导过0到1产品设计 |

## 四、典型工作

来源：腾讯、美团、高校人才网 JD 交叉归纳。

- 负责产品（移动端/桌面端/Web端）的交互与视觉设计——腾讯、美团
- 参与产品需求讨论，从用户体验角度提供设计建议——美团、高校人才网
- 输出信息架构、页面流程、线框图、高保真原型及交互说明文档——腾讯
- 开展用户调研、可用性测试，基于数据反馈优化设计方案——腾讯
- 建立并维护设计规范与组件库，提升设计效率与一致性——高校人才网
- 与产品、开发紧密配合，跟进设计落地效果，确保高还原度——全部JD
- 跟踪设计趋势，持续优化产品视觉表现与交互体验——高校人才网

## 五、给大学生的对照指南

| 你有这个 | 怎么对标 JD |
|----------|-----------|
| 一套完整的作品集（2-3个完整项目） | 对应所有JD的硬性要求——作品集是入场券 |
| 熟练掌握 Figma + 做过高保真原型 | 对应"熟练使用Figma等设计工具""输出高质量视觉方案" |
| 做过用户访谈或可用性测试 | 对应腾讯JD"开展用户调研、可用性测试"——大厂区分项 |
| 理解 iOS/Android 设计规范 | 对应"了解各端设计规范"——腾讯、美团JD |
| 能独立完成一个产品的交互流程设计 | 对应"信息架构""用户流程设计"——UX岗核心能力 |
| 有动效设计经验（AE/Principle） | 腾讯JD明确要求的加分项 |
| 搭过组件库或设计系统 | 对应高校人才网JD"建立并维护产品设计规范" |
