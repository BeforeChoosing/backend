# 职业价值观——硬信号（11项）

Agent 可根据岗位JD、公司/行业公开信息直接判断匹配度。

| 项目 | 价值观解释 | Agent 判断规则 |
|------|-----------|---------------|
| 艺术创造 | 从事各种形式的艺术创作工作。比如绘画、作曲。 | 判断岗位是否属于设计/创意/内容创作类。JD中岗位职能、产出物类型可直接区分。 |
| 身体挑战 | 工作与身体力量、速度和灵敏性相关。 | 判断岗位是否涉及体力劳动。JD中工作场景描述（户外/车间/工地 vs 办公室）可直接区分。 |
| 人身安全 | 工作中身体的安全和健康不受侵害。 | 判断行业安全风险等级。可参考行业公开安全记录、岗位是否涉及高危场景。 |
| 薪酬收入 | 收入能够满足自己的期望，维持比较高的生活标准。 | 校招薪资标准化程度高，可查询公开数据（如 offershow、脉脉、公司官方薪资范围）与用户期望值做对比。 |
| 社会认同 | 所从事的工作所在的工作单位在人们心目中有较高的社会地位，从而使自己得到他人的重视与尊重。 | 判断公司品牌知名度与行业声望。可参考公司市值/估值、行业排名、主流媒体曝光度。 |
| 团队合作 | 团结共同开展工作并实现团队目标。 | 分析JD措辞中协作相关关键词（"跨部门""协作""项目制" vs "独立负责""个人产出"）判断协作密度。 |
| 工作环境 | 能够在一个自己满意的城市、区域等社会或空间环境下工作。 | 提取JD中的工作地点、远程政策、出差频率，与用户偏好城市/区域做匹配。 |
| 利他助人 | 可以直接或间接地帮助他人，做有益于社会的事情。 | 判断公司业务是否属于公益/教育/医疗/社会服务类。业务方向为公开信息，可直接分类。 |
| 社会价值 | 能够为集体做贡献，保家卫国，或促进世界和平。 | 同上，判断公司使命是否指向公共利益或社会进步。 |
| 信仰与道德 | 工作符合自己的精神追求与信仰。 | 判断公司业务方向与价值观声明是否与用户信仰/道德立场冲突（如军工、烟草、博彩等行业选择）。 |
| 环保 | 做有益于自然生态环境的工作。 | 判断公司业务对自然环境的影响方向。可参考行业属性、公司ESG报告、环保争议记录。 |

# 职业价值观——软信号（5项）

Agent 可给出参考判断，但须标注不确定性，提示用户入职后验证。

| 项目 | 价值观解释 | Agent 参考判断规则 | 不确定性说明 |
|------|-----------|-------------------|-------------|
| 追求新意和多元化 | 希望能经常接触新的工作环境、新的事情以及不同的人群。 | 判断行业类型：咨询/互联网轮岗/项目制 vs 传统职能深耕型。行业节奏差异可作为参考信号。 | 实际日常多样性取决于具体业务阶段和直属上级风格，行业信号无法捕获组内差异。 |
| 创新 | 能够提出新的观点、项目、架构或提升工作效率方法，并有机会被采纳和实践。 | 参考公司在行业内的创新声誉、产品迭代节奏、研发投入占比。 | 实际创新自由度取决于团队文化和上级授权，公开信息只能反映公司层面偏好，不反映个人体验。 |
| 工作生活平衡 | 能够平衡家庭，不影响自己履行家庭责任。 | 参考行业加班文化名声、员工社区评价（脉脉等）、公司是否在JD或公开材料中明确工时政策。 | 同一公司内不同部门、不同业务阶段的差异可能极大，行业名声只能作为粗略方向。 |
| 健康 | 自己的身体与心理持续稳定的健康。 | 参考行业工作强度信号：投行/咨询/互联网通常高强度，体制内/传统行业相对可预期。 | 健康影响高度因人而异，且取决于具体团队节奏和个人应对能力，行业信号仅供参考。 |
| 家人认同 | 能够得到父母、亲戚等家人的认同。 | 参考公司/行业的社会声望与公众认知，推断典型家庭对该职业的接受度。 | 每个家庭的价值排序不同，不能仅凭社会声望外推。agent 应提示用户自行判断。 |
